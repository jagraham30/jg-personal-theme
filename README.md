\# JG Personal Theme



A custom WordPress theme for my personal portfolio site, built from scratch

while working through a theme development course.



\## Features

\- Front page, blog, projects, about, and contact templates

\- Blog posts organized by category



\## Development

Built and tested locally with LocalWP.



1\. Clone this repo into `wp-content/themes/`

2\. Activate it under Appearance → Themes



\## Status

Work in progress.
